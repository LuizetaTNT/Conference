# Gender and Sexualities Conference 2027

A portable, responsive static website using the supplied Astarte branding. The package contains a homepage and all nine requested sections. It uses standard HTML, CSS and JavaScript, with no installation, account, framework or build step required.

## Preview on your computer

Extract this ZIP, then open `index.html` in your browser. Keep the assets folder and HTML files together. Navigation and the mobile menu also work when opened locally. Astarte and institutional links need an internet connection; the website itself uses no external fonts, scripts or remote images.

## Upload to GitHub and publish with GitHub Pages

1. Create a GitHub repository, for example `gender-sexualities-conference-2027`.
2. Choose **Add file → Upload files**. Upload the CONTENTS of the extracted `conference-2027` folder. `index.html` must be at the repository root, beside `assets` and the other HTML files, rather than inside a second folder. Ensure `.nojekyll` is included where your operating system allows hidden files to be selected; it is optional for this plain static site.
3. Commit the files to your `main` branch.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
5. Wait for GitHub to display the published website address. All site links use relative paths, so both repository Pages sites and custom domains are supported.

This download does not create a GitHub repository or publish anything automatically.

## Edit the website

Edit any `.html` file in a text editor, or using GitHub’s Edit button. Save or commit the file to update it. The site content is fully present in HTML and remains readable with JavaScript disabled.

- `index.html`: homepage and overall conference introduction.
- `about.html`: organisers and conference focus.
- `programme.html`: final programme and abstracts.
- `astarte-journal.html`: journal description and official journal link.
- `registration.html`: registration link, fees, deadlines and cancellation terms.
- `speakers.html`: confirmed speaker biographies and keynotes.
- `university-of-malta.html`: University, Faculty and Department links.
- `visa.html`: official visa resource and conference documentation enquiries.
- `accommodation-and-logistics.html`: venue, travel and hotels.
- `general-information.html`: practical questions, access support and privacy.
- `assets/styles.css`: all colours, typography and responsive layout.
- `assets/site.js`: accessible mobile navigation only.
- `assets/astarte-logo.png`: supplied journal logo, included unchanged.

The shared header, footer and conference essentials are repeated in each HTML page. When changing dates, venue, contacts or navigation, update every occurrence across the HTML files. No hosting-provider-specific configuration is included.
